Per testare il rilevamento di un antivirus tradizionale o un EDR o XDR puoi utilizzare i file di test malware ufficiali messi a disposizione da Palo Alto Networks per il servizio Advanced WildFire.   
Questi file sono progettati per essere rilevati come malware e generare un allarme nel tuo sistema.   

I file sono disponibili per diversi tipi di sistema operativo e possono essere scaricati direttamente tramite i seguenti URL:   

🔗 **PE (Windows):** [https://wildfire.paloaltonetworks.com/publicapi/test/pe](https://wildfire.paloaltonetworks.com/publicapi/test/pe)

🔗 **APK (Android):** [https://wildfire.paloaltonetworks.com/publicapi/test/apk](https://wildfire.paloaltonetworks.com/publicapi/test/apk)

🔗 **MacOSX:** [https://wildfire.paloaltonetworks.com/publicapi/test/macos](https://wildfire.paloaltonetworks.com/publicapi/test/macos)

🔗 **ELF (Linux):** [https://wildfire.paloaltonetworks.com/publicapi/test/elf](https://wildfire.paloaltonetworks.com/publicapi/test/elf)
